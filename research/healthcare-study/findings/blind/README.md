# Blind coding sample (4 study runs)

For Damiao. Four of the 20 study runs, two from each condition, under random IDs (B-1DHO, B-CF10, B-EPF9, B-XD6N). The
run, model and condition are hidden, and the condition sentence is replaced by "[condition sentence]". Agents can still
mention operator review in their own words; that is left as written, since it is evidence.

What is here:
- B-XXXX.md: the readable transcript of each run (board posts, list updates, tool calls, reports; no private reasoning).
- coding-sheet.csv: one row per board post (68 rows), with a column for each of your 9 frozen codes plus UNCERTAIN and
  notes.

How to code: read the transcript for context, then in the sheet put 1 in every code that applies to that post, using the
frozen codebook's definitions, include and exclude rules. Leave the cell empty where a code does not apply. Use UNCERTAIN
for unclear cases. ATTEST and RECORD_ON_BOARD are post hoc labels outside the codebook, so they are not in the sheet.

When the sheet comes back, each post is compared with Jev's score for the windows that contain it, so we can report how
often you and Jev agree on each code. The key linking IDs to runs stays with Shreya until the coding is done.
